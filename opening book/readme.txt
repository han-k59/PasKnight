Thanks for sharing it.

For comparison of chess engines, use an opening book in the GUI program Cute Chess where you can control it

1) In setting Tournament, play each move twice
2) In setting Games, set depth to 16 plies (8 moves)


Else if you want PasKnight to operate independently just place the extracted opening book in the same directory as PasKnight. It will read any book available. To disable it just remove it.
